Notes about the data

  • Modified skill values are highlighted in yellow-orange. Skills remain listed when their required research has not been selected.
  • A + before build time means additional morph, merge, or installation time; it excludes the parent units' build time.
  • Any units with charge-based production (e.g. Artanis) uses the charge cooldown time as the build time. For Stukov, the unit's build time is displayed, and not the charge time.
  • For multiple-spawned units (e.g. Zerglings), resource costs are divided by the number of units spawned.
  • Biomass uses the selected amount. Other buffs with multiple stacks use their maximum value.
  • Upgrades that do not change the displayed unit stats or skills are listed without a checkbox.
  • Since numbers are calculated, there may be small rounding errors.

If you prefer the old unit stats page, it's still available.

Note: All data generated on this site is based on Brutal difficulty. Timings, compositions and other elements may differ on easier difficulty levels.
